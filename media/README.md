# Media

This directory contains public media supporting the Fujitsu FUTRO S930 / D3313-E1 research documentation.

## Structure

- `photos/` — photographs of hardware, boards, components, programmers, connectors, and test setups
- `screenshots/` — screenshots of firmware tools, diagnostics, operating systems, and analysis results
- `diagrams/` — original diagrams, layouts, wiring illustrations, and explanatory graphics

## Privacy and safety

Before publishing media, remove or redact unnecessary:

- serial numbers;
- UUIDs;
- full MAC addresses;
- PC IDs;
- usernames;
- email addresses;
- local file paths;
- authentication tokens;
- API keys;
- QR codes and barcodes;
- EXIF/GPS location data;
- HDCP or other machine-specific secrets.

Do not publish personalized raw firmware images in this directory.

## File naming

Use descriptive lowercase filenames with hyphens.

Examples:

```text
d3313-e1-mainboard-overview.jpg
ch341a-soic8-connection.jpg
fujitsu-recovery-jumper-position.jpg
flashrom-internal-read.png
realtek-rset8168-mac-zero.png
oem-region-comparison-diagram.png
```

Where appropriate, include the image source or context in the related documentation.

Third-party images must not be uploaded unless redistribution is permitted.

Original project media is subject to the repository licensing terms unless explicitly stated otherwise.
